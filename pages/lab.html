Offline-first rules

  • Room is the single source of truth
  • UI never calls the network directly
  • Optimistic updates + background reconcile
  • WorkManager for constrained sync
  • Conflict policy per entity type

Module boundaries

  • :app — thin shell, navigation
  • :feature:* — screens + feature VMs
  • :core:domain — pure Kotlin
  • :core:data — Room, network, repos
  • :core:ui — shared Compose components

Hilt / DI

Scoped modules per layer; test doubles at boundaries

Testing pyramid

Unit → repository → Compose UI → few E2E

Observability
